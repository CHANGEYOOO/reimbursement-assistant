# Windows 1.34 使用与验收说明

本版以 Mac 1.34 为功能和业务规则基准，推荐在 Windows 11 64 位电脑使用，不支持 32 位 Windows 或 Windows 7／8。软件、界面和安装程序均为中文，图标与 Mac 相同。

## 安装与退出

打开 `ReimbursementAssistant-Windows-1.34-Setup.exe`，选择安装位置并按提示操作。默认只安装到当前用户的程序目录。若电脑缺少 OCR 所需的 Microsoft VC++ 组件，安装程序会询问后使用随包提供的微软运行库进行安装。

关闭主窗口后软件继续在右下角托盘运行；从托盘菜单选择“退出”才会停止。启动、通知和登录启动都可以在“设置”调整。

程序未使用商业代码签名证书；首次运行若出现 Windows 信誉提示，请先核对文件来源和 SHA256，再决定是否继续。

## 主要操作

- 左侧创建或选择项目，导入订单截图；也可以从文件夹拖入图片，继续追加。
- 栏目与导出 Excel 一致：序号、日期、名称、图片、金额。
- 选中订单或发票后，统一在右侧预览；支持适合宽度、缩放和 PDF 翻页。
- 日期直接输入八位数字，例如 `20260924`，实时补成 `2026-09-24`。
- 拖动订单调整顺序；金额搜索和“只看待处理”不会改变完整导出范围。
- 订单与截图自动保存；选择分类自动填写默认用途并标记人工核对，手动用途保留。
- 可食用、饮用的商品归餐食，其他采购物品归道具采购；退款和收入不作为支出自动报销。
- 只有金额不确定时提供候选；本地判断失败时可自动请求已配置的 AI，手动填写的内容保留。
- “发票箱”统一收票，“项目发票夹”保存本次报销发票。发票无需逐条对应订单。
- 手动导入直接按发票保留，只提取金额和抬头。邮箱附件自动筛选普通/专用电子发票；行程单、客票、明细等排除，无法判断保留待确认。
- 发票按邮件收到日期分月，点击月份选中当前筛选中未加入项目的合格发票；绿色标记显示已加入的项目，操作栏显示已选金额。
- QQ 邮箱启用后新收到的附件自动下载识别，历史附件仍按需下载。仅有下载链接的邮件会保留提醒，需到 QQ 邮箱处理。
- 缓存上限默认200 MB，可自行修改。只清理可重新下载的邮箱缓存，项目副本、手动导入和已导出资料保留。
- 发票导出独立文件夹，命名为“导出日期-发票总金额”；不放入 Excel，也不按公司抬头拆分。

## 数据与密钥

资料保存在 `%LOCALAPPDATA%\报销单助手`。安装目录与资料目录分开，卸载保留项目和设置。Windows API 密钥、邮箱授权码按当前 Windows 用户加密保存，不应把设置文件当作可跨电脑直接使用的密钥备份。

需要迁移或备份时，先退出程序，再备份资料目录；迁移到另一用户或电脑后需要重新填写密钥。订单截图及发票原件不要仅依赖可清理缓存备份。

## 请在真实电脑检查

1. 安装、首次启动、关闭隐藏、托盘恢复与退出；高分屏及最小窗口下的按钮是否完整。
2. JPG、PNG、HEIC 批量导入，连续拖入两批；右侧预览和拖动排序。
3. 八位日期输入、回删、金额候选点选、人工修改、用途分类和批量核对。
4. 导出 Excel 用 WPS 打开，检查栏目、图片、合计及打印布局。
5. 切换项目、退出重启、删除及撤销，核对项目和排序保存正确。
6. 配置 DeepSeek／阿里 API，检查不确定字段自动补全、手动填写不被覆盖。
7. 手动导入发票应直接保留；邮箱自动附件区分发票、非发票及待确认。开启独立授权后，待确认自动 AI 兜底，采用 AI 明确结果。
8. 发票按月选择、项目归属、金额差额和独立文件夹导出。
9. 连接真实 QQ 邮箱，发送新发票、ZIP及行程单，检查新票自动识别、历史附件按需下载、日期使用收件时间。
10. 设置缓存上限、手动清理，再查看发票，检查项目副本保留且清理后的缓存不会反复自动下载。
11. 通知开关、通知点击、开机启动及网络中断后的重试。
12. Windows 设置中卸载，确认项目资料保留。

已建立与 Mac 相同文本/布局的37组对照样本。两端 OCR 引擎不同，模糊图片的文字提取可能有差别；业务规则对齐不代表逐张图片文字完全相同。Windows 按既定业务规则拒绝“退款成功”同时出现“实付”的混合文本，未复刻 Mac 1.34 在该边界的误取金额行为。
