# 报销单助手

把零散的订单截图，整理成一份可以用 WPS 打开和打印的 Excel 报销单。

导入截图后，软件会自动填写金额、日期和用途。你可以修改识别结果、调整顺序，再导出报销单。

还可以连接 QQ 邮箱自动下载、识别新发票，再加入对应项目，查看发票是否足额，并单独打包导出。AI、邮箱、通知和登录启动都可以在统一的“设置”窗口中调整。

## 下载与安装

### Mac 版

[下载 Mac 1.27 安装包](https://github.com/CHANGEYOOO/reimbursement-assistant/releases/download/v1.27.0/ReimbursementAssistant-macOS-1.27.dmg)

适用于 **Apple 芯片的 Mac，需 macOS 15 或更新版本**。

1. 打开下载的安装包。
2. 将“报销单助手”拖入“应用程序”文件夹。
3. 从“应用程序”中打开软件。

如果首次打开提示“Apple 无法验证”，请前往“系统设置 → 隐私与安全性”，找到该提示并选择“仍要打开”。请确认安装包来自本项目的下载页面。

### Windows 版

请到 [全部版本下载页面](https://github.com/CHANGEYOOO/reimbursement-assistant/releases) 查找 Windows 安装包。

Windows 版暂未同步 Mac 的最新功能，以下说明主要适用于 Mac 1.27。

## 快速开始

### 1. 导入订单截图

新建报销单并填写标题，点击“导入截图”，一次选择多张图片。

也可以直接把图片从文件夹拖入软件，之后还能继续追加。支持 JPG、PNG 和 HEIC 图片。

### 2. 检查识别结果

软件会自动识别日期、用途和金额。

- **金额不确定：**点击正确的候选金额，或直接手动填写。
- **用途不合适：**修改分类或用途文字。选择分类后会自动填写对应的用途名称。
- **需要查看原图：**选中订单查看右侧截图，点击图片可以放大。
- **需要调整顺序：**按住订单所在行拖动。
- **导入错误：**点击该行的删除按钮。

手动填写日期时，只需输入 `20260924`，软件会实时补成 `2026-09-24`。

### 3. 集中处理有问题的订单

勾选“只看待处理”，即可集中处理尚未完成的记录。当前选中的订单处理完成后，会自动接续下一笔。

也可以点击“查看待处理问题”，直接跳到第一条需要处理的订单。

想查找某个金额时，在搜索框输入数字即可。例如输入 `39`，可以找到 `39.00`、`139.50` 等金额。

搜索和筛选只影响屏幕显示，导出时仍包含完整报销单。

### 4. 导出 Excel

处理完问题后，点击“导出 Excel”，选择保存位置即可。

导出的栏目顺序为：

**序号 → 日期 → 名称 → 图片 → 金额**

表格末尾附有合计，可用 WPS 打开、检查和打印。如果还有未完成的项目，软件会提示你先处理。

## 保存与继续编辑

报销单会自动保存在当前电脑，不需要每次手动保存。

下次打开软件可以继续编辑，也可以通过“打开 / 管理报销单”查找、重命名或删除之前的报销单。

导入的截图会复制到报销单中，软件不会修改原始文件。自动保存不是云端备份，重要资料建议另行备份。

## 发票箱与项目发票夹

左侧的“发票箱”是公共收票区，每个项目的“项目发票夹”保存本次报销要用的发票。发票不需要与订单截图一一对应，只需按你的报销要求补足总金额。

1. 在发票箱中同步邮箱，或手动导入图片、PDF、ZIP。
2. 按收件月份查看发票，也可以按购买方抬头、日期范围、是否已加入项目筛选。点击“本月”等月份标题，可批量选择当前筛选下尚未加入项目的合格发票。
3. 查看已选张数和金额，点击“加入项目”，选择对应报销单。卡片会用绿色标记显示“已加入 · 项目名称”。
4. 进入项目发票夹，检查金额和差额，再点击“导出发票文件夹”。

也可以从项目发票夹点击“从发票箱选择”补充发票。加入项目后，原件仍保留在发票箱；从项目移除后可以重新分配。相同文件不能重复加入不同项目。

项目发票夹仍支持直接导入。只接收“电子发票（普通发票）”或“增值税电子普通发票”，自动排除行程单、电子客票、报销单等附件，无需你确认文件类型。多页 PDF 每页都会检查；票面不清或关键字段不足的文件也会被排除。

金额优先读取文件名中的明确金额，否则识别票面的价税合计；识别不准时可以手动修改。可以删除单张或勾选批量删除发票箱记录，项目副本和邮箱原件不受影响。

导出的文件夹例如 **2026-10-26-1280.50**，表示“导出日期-发票总金额”。图片和 PDF 保持原格式，不会放入 Excel，也不会因重复导出而覆盖已有文件。订单金额还有待处理项时，发票差额会标为“暂估”。

## 连接 QQ 邮箱与后台收票

1. 从左侧“设置”进入“QQ 邮箱”。
2. 在 QQ 邮箱开启 IMAP 服务，获取授权码，再填入软件。授权码不是 QQ 登录密码。
3. 选择从哪天开始收集，测试连接后保存并启用。
4. 在“设置 → 后台与通知”中，按需开启新发票通知和登录启动。

**新版首次开始同步后，新收到的发票附件会自动下载并识别。** 合格发票进入发票箱，其他文件进入“已排除附件”；下载失败会在后续同步中重试。

启用前的历史附件仍按需下载，避免首次连接大量下载。只含下载链接的邮件仍需到邮箱中手动下载。软件不会改变邮件已读状态或删除邮件。

发票按邮件收到的日期从新到旧排列，分为本月、上月和更早月份；手动导入使用导入日期。暂不直接同步 QQ 邮箱自带的发票助手；邮件只有下载链接时，请在邮箱中下载后手动导入。

关闭主窗口后，软件仍会后台收票。顶部菜单栏图标可以打开窗口、查看同步状态、立即同步和退出；选择“退出”或按 `⌘Q` 才会停止。电脑需要联网且未休眠，默认每 5 分钟检查一次。

通知和登录启动默认关闭，可在设置中开启。新发票按批合并通知，点击通知进入发票箱。首次启用可能需要允许系统通知或登录项权限。

## 缓存管理

在“设置 → 缓存管理”中，可以查看缓存占用、设置大小上限或手动清理。默认上限为 200 MB，可以自行修改。

超过上限后，软件会把最久未使用、可从邮箱重新下载的缓存文件移入废纸篓，保留发票记录、金额和项目归属。项目副本、手动导入文件及已导出文件不会被清理。清理后的附件不会反复自动下载，需要时再取回；重要资料请另行备份。

## AI 辅助识别（可选）

**不开启 AI，也可以正常使用软件。**

如果希望软件进一步判断复杂订单中的金额、日期和用途，可以在“设置 → AI 辅助识别”中配置 DeepSeek、阿里百炼等服务。

填写服务商提供的密钥、模型名称和服务地址，测试连接成功后保存并启用。

开启后：

- 本地识别无法确定的内容，会自动交给 AI 辅助处理。
- 能确定的结果直接填入，无需再次点选确认。
- 金额仍不确定时，会保留候选供你选择。
- 日期优先采用支付日期，也可以采用下单等参考日期；只有月日时会补上当前年份。
- 你手动修改的字段会保留，其他未修改字段继续识别。

AI 服务可能收费，具体以服务商规则为准。

## 常见问题

### 截图和密钥会上传吗？

普通文字识别在电脑本地完成。

启用 AI 后，软件会将截图中识别出的文字发送给你配置的 AI 服务，不上传截图原图。文字中可能包含商家、订单等个人信息，请按需开启。

API 密钥和邮箱授权码保存在 Mac 钥匙串中，不会放进导出的报销单或发票文件夹。邮箱收票与发票识别不会把邮件内容发送给 AI。

### 为什么还有订单需要手动处理？

截图可能包含多个金额、模糊文字或不完整信息。软件无法确定时，会保留提示，方便你选择或补充。

### 截图中的金额是负数怎么办？

支付截图中的负数扣款，会按正数支出填写。退款或收入不直接作为报销支出自动填入。

### 所有订单都要勾选“已人工核对”吗？

不需要。显示“可导出”且没有其他问题的订单，可以直接导出。

你仍可以逐条核对，或使用“全部标记已人工核对”。缺少金额、日期或用途的记录，需要先补齐。

### 发现识别错误怎么办？

所有自动填写的日期、用途和金额都可以手动修改。提交报销前，建议快速检查金额、截图和合计。
