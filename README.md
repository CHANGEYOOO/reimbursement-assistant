# 报销单助手

这款工具把支付或订单截图整理成可用 WPS 打开和打印的 Excel 报销单。Mac 版还可保存报销单草稿、管理发票并单独导出发票文件夹。截图文字识别和发票处理在本机完成，原文件不会被修改；可选的 AI 用途分类会将识别文字发送到你配置的服务商，截图原图不会上传。

## 打开

从 [Releases](https://github.com/CHANGEYOOO/reimbursement-assistant/releases) 下载 Mac DMG，双击后把“报销单助手”拖到“应用程序”文件夹。如果首次打开时 macOS 提示来源未知，在 Finder 中按住 Control 点按应用，选择“打开”，再按系统提示确认。

需要重新生成独立应用时运行 `./scripts/build-app.sh`；需要重新生成安装镜像时运行 `./scripts/build-dmg.sh`。构建需要安装 Swift 命令行工具。

## 使用

1. 新建或打开报销单，填写标题，点“导入截图”选择多张 PNG、JPEG 或 HEIC；也可以从 Finder 文件夹把这些图片直接拖入软件窗口，支持分批追加。草稿自动保存在本机，导入的截图会复制到草稿中。
2. 等待本机识别完成，逐条核对日期、用途和金额。日期优先取截图中的支付或交易日期；手动输入 `20260924` 时会自动显示为 `2026-09-24`。金额无法确定时可点击候选金额；手动选分类会自动标记“已人工核对”，也可以用“全部标记已人工核对”处理当前报销单。重复截图会提示并排除在合计与导出之外。
3. 单击记录可蓝色高亮选中，按住该行拖动可调整顺序。点击缩略图查看原图大图，再点击大图收起。确认底部条数和合计。
4. 点“导出 Excel”，在系统保存窗口选择位置。若按钮不可用，窗口底部会说明需补全的项目。保存后用 WPS 打开 `.xlsx`，检查图片、金额和打印预览。

导出表的五列依次为“序号、日期、名称、图片、金额”，末尾有合计。关闭应用后可从保存的草稿继续编辑。

Mac 1.9 可在订单列表上方实时搜索已填写的金额，例如输入 `39` 可找到 `39.00`、`139.50`。勾选“只看待核对”可集中处理缺少金额、有效日期、用途或尚未确认识别提示的订单；两个条件可同时使用。搜索与筛选只影响列表显示，保留原序号，合计和 Excel 导出仍包含完整报销单。

Mac 1.10 的“打开 / 管理报销单”可重命名草稿，或将草稿及其保存的截图、发票一起移入废纸篓；原始导入文件不受影响。移走当前草稿后会打开最近的另一张报销单，没有其他草稿时新建一张空白报销单。

Mac 1.11 将报销单管理、导入导出、搜索筛选分层展示。每条订单显示明确的处理状态；点击“导出 Excel”时若还有问题，会集中列出所有待处理订单，点击即可清除筛选并定位到原记录。导出校验及自动人工核对规则保持原有行为。

界面优化前的 Mac 1.10 已保存为本地 Git 标签 `baseline-mac-1.10-20261026`；安装包与源码快照在 `build/baselines/mac-1.10-20261026/`。

Mac 1.12 在订单区增加可收起、可调整宽度的右侧截图预览，选中订单后可滚动查看长图、缩放并点击全屏放大。订单删除和排序可用底部“撤销”或 `⌘Z` 撤销，切换报销单会清空撤销历史；文字编辑中的 `⌘Z` 仍用于撤销文字输入。发票夹将订单总额、有效发票金额、差额和待确认数量分开展示。

Mac 1.13 点击“查看待处理问题”会直接定位到当前排序中最靠前的待处理订单，清空搜索和筛选、蓝色高亮并显示右侧截图；再次点击会重新查找当前最靠前的问题。导出 Excel 时仍保留完整问题清单。若订单本身没有问题而仅缺报销单标题，会显示标题填写窗口。

## Mac AI 辅助识别（1.18）

在“AI 设置”中选择 DeepSeek、阿里百炼或自定义 OpenAI 兼容接口，填写完整 Chat Completions 地址、模型名称和 API Key；每个服务商独立保存。密钥只存 Mac 钥匙串，留空保存会保留已有密钥。阿里地址需要匹配密钥地域，也可填写业务空间专属地址。可用“测试连接”发送固定测试文本验证配置（会产生 API 调用费用）。

AI 默认关闭。保存并启用后，新导入订单在本地识别结束时自动接续 AI；当前已导入或打开草稿中的未确定字段也会自动处理。用途、金额和日期分别判断，某一项已经手动填写不妨碍其他缺失项接续识别。AI 在同一次请求中判断，仅发送本机识别文字，不上传原图。不做失败循环重试，需要时仍可点“AI 辅助识别”。

金额必须完整出现在识别文字中，不能推算或从订单号截取；负数扣款按正数支出处理，退款或收入不自动填写。日期已有年份时保留原文；只有月日时按软件运行时的当前公历年份补全，并在 AI 依据中注明。日期优先采用支付或交易日期，没有时自动采用 AI 推荐的有效原文日期（例如下单日期），无需点击候选，并标注“参考日期”。没有有效日期时才需要手动填写。不存在的日期不会填入，原本明确有效的金额、日期继续保留，人工修改优先。

AI 明确且通过原文校验的结果会直接填写，字段完整且没有其他问题时即可导出，无需再点击候选或勾选核对。状态显示“AI 已识别”，不会伪装为“已人工核对”。金额、用途不确定时继续保留候选或待处理状态，自定义用途文字会保留。请求期间手动修改任意字段都会使旧 AI 结果失效。API 失败可继续手工处理，不会切换服务商。AI 识别标记可随草稿保存，旧草稿仍兼容；候选日期和说明仅在当前会话显示。

## Mac 发票夹

底部显示待确认发票数量，合计只包含金额有效且没有识别异常的发票；只要还有发票待确认，就会显示橙色提示，补全金额后才能导出。

切换到“发票夹”，可批量导入 JPG、PNG、HEIC、PDF 或包含这些发票的 ZIP。ZIP 中的汇总表不会计入发票。发票金额优先从文件名读取；文件名没有明确金额时读取 PDF 内容或进行本机文字识别，识别不准可手动修改。界面显示发票合计与订单金额的差额。

导出发票时选择一个父文件夹。软件按发票购买方抬头分组，各组另建文件夹，名称为“导出日期-该组发票总金额-购买方抬头”；每张发票保持原格式。购买方识别不到时可在发票夹填写备用抬头。发票不会放进订单 Excel。

## Windows 版

从 [Releases](https://github.com/CHANGEYOOO/reimbursement-assistant/releases) 下载 Windows EXE，复制到 64 位 Windows 电脑，双击运行即可。Windows 版沿用同一图标和五列顺序，支持批量导入或拖入 PNG、JPEG、HEIC，核对后导出 `.xlsx`。金额无法确定时可点击候选金额，点选后自动标记人工核对。识别所需的中英文数据已封装在 exe 中，截图在本机处理。Windows 上的实际操作和 WPS 打开效果由用户手动验收。如识别时提示缺少原生 DLL，请先安装 [微软 Visual C++ x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

重新生成 Windows 版需要 .NET 10 SDK。在项目目录执行：

```sh
dotnet publish Windows/ReimburseApp/ReimburseApp.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=None -o build/Windows版-1.2
```
