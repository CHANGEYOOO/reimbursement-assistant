# Mac 1.28 原生交互优化实施方案

基准：Mac 1.27（d91b3fb）。Windows 开发保留在 codex/windows-mac127-parity（30af3b1），本次不继续修改。

## 设计与边界

- 不重写数据模型或业务层。现有项目与报销单在代码中为同一 Draft 实体，界面统一称“报销项目（报销单）”，不虚构新的层级；项目发票夹仍隶属同一 Draft ID。
- Draft 列表采用稳定顺序，打开/选中不修改排序依据；真正变更才更新时间。侧栏作为主要入口，原生右键菜单准确作用于点击对象，删除须确认范围。
- 根视图安装共用附件预览层：当前窗口中央、原比例、适配窗口、减少动态效果，点击主体/背景/Esc退出。图片及PDF共用；PDF页码/滚动/捏合不误触关闭。订单右栏保留，发票箱无常驻预览栏。
- 发票内容缩略图异步生成且有界缓存；未下载不偷偷下载历史文件；预览读取原文件，不拉伸缩略图。
- 无附件的发票邮件通过可收起、可拖宽度右侧栏按需加载正文，内存缓存；HTML禁脚本、表单、框架及外部资源，显式链接点击才开系统浏览器。邮箱只读，不改已读/邮件/发票归属。
- 设置“关于与更新”：从Bundle读取版本与构建时仓库配置；GitHub正式Release、数值版本比较、架构匹配、明确错误。仅显式点击下载，不自动安装。
- 仅移除订单页手动AI入口和失效UI状态，自动AI和现有配置保留。

## 分工

1. ReviewView / DraftStorage：导航、稳定排序、上下文菜单、移除手动AI入口；接入预览根层和邮件布局。
2. ImagePreview / OrderPreviewPanel / InvoiceInboxView：共用预览、异步缩略图；通过根层环境控制预览状态。
3. QQMailbox / QQMailboxParser / 邮件详情视图：原始正文按需读取、安全HTML与下载链接、邮件列表右栏布局。
4. GitHub更新检查、设置、版本/构建配置、完整编译及交付由主代理负责。

## 验证与交付

- 定向离线检查：无变更打开不重排；右键对象；版本比较/过滤/架构/错误；MIME解码/链接和HTML安全；预览尺寸/页码/缩略图缓存。
- 编译完整SwiftUI应用，验证DMG，提供Mac1.28安装包和修改/测试/限制说明。
- 不在自动检查中读写真实项目、访问真实QQ或调用付费AI；真实邮箱与交互验收明确交给用户。
- 所有实际文件删除只用 /usr/bin/trash；失败停止并报告。测试文件保留。
