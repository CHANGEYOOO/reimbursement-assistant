# Mac 1.33：恢复稳定本地规则，自动接续AI兜底

后续Mac1.34已按用户要求调整为[手动导入免筛选、AI明确结果优先](mac-1.34-manual-import-and-ai-authority.md)。本页为历史版本记录。

## 修改原因

Mac1.31引入的严格筛选，把双方税号、字段逐项绑定及金额勾稽作为所有普通发票的接纳门槛，导致原来可识别的常见发票大量进入待确认。Mac1.32保留了这些门槛，本次按用户要求恢复严格改动前Mac1.30的普通发票本地识别标准。

## 当前流程

1. 普通发票PDF和图片优先使用恢复的发票标题、号码、日期、买卖方及价税合计特征规则，并恢复本地OCR补充。无需强制双方税号、传统发票代码或金额税额勾稽齐全。
2. 保留明确行程、报销、订单及消费明细等排除规则和三类状态。加密/损坏/无法读取或混合页不强行确认，不删除原件。新增票种和OFD/XML既有结构支持保留。
3. 已授权时，本地无法确定会自动交给AI，不再显示手动AI识别按钮。新导入、打开项目、保存AI设置和发票箱启动检查都会接续符合条件的已下载待确认文件。不自动重新下载已清理的历史缓存附件。
4. AI目标发票仍要求严格独立字段、票种及结构复核；无法判断才保留人工确认。人工确认入口留给最终无法可靠判断的文件。
5. 本地接纳策略升为4以重新检查旧记录；AI严格复核版本仍为3，避免只因本地回退而让原有AI缓存失效、重复消耗额度。

## 旧记录及金额

以前被严格规则卡住的已保存附件会重新本地判断。恢复发票时补缺失金额，仍优先文件名金额，再用票面识别；已有有效金额和处理中人工修改不覆盖。切换项目后，旧目录的识别任务不能写入新项目。
