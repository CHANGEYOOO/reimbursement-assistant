# Windows 1.34 同步计划

以已发布 Mac 1.34 和已有 Windows 1.27 为基准，不改变 Mac 代码与用户数据。

1. 恢复已完成的 Windows 基础：保存、订单识别、QQ、发票箱、缓存、托盘、安装器。
2. 同步项目侧栏与稳定保存、统一右侧预览、邮件详情、GitHub 更新检查。
3. 同步发票本地三态、结构化格式、手动导入信任、自动 AI 兜底及独立授权和缓存。AI 明确结果优先，错误继续待确认。
4. 离线规则检查，Windows CI 完整编译、启动/OCR和安装器检查，交付中文 EXE。真实 Windows、邮箱和付费 API 由用户验收。

邮件详情禁止自动加载外部资源。手动导入不上传 AI 进行票种判别。源文件、项目副本及已有导出文件不纳入缓存清理。
