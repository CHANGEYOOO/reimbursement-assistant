# Mac1.34：手动发票免筛选，AI结果优先

按用户最新要求调整：

- 手动选择或拖入发票箱、项目发票夹的文件视为用户提供的发票，不进行本地或AI票种判断。金额与抬头仍正常识别，缺金额只提示补金额，不再因文件类型进入待确认。
- 手动ZIP内附件沿用手动信任标记；仍检查支持格式、文件可读性及ZIP路径/大小安全，不删除用户源文件。
- 发票箱旧的“手动导入”来源记录会直接保留为发票；重复手动导入可提升以前的待确认/非票记录，恢复缺失缓存，保留已有金额且不新增重复行。分配项目时保留手动来源标记。
- 手动信任不随本地规则版本变化而失效。导入后重置会隐藏新记录的抬头、日期、状态筛选，并显示导入结果。
- 邮箱自动附件仍先本地判断，本地待确认后自动AI兜底。AI明确返回目标发票或非目标附件时，采用AI结果，不再要求本地字段复核通过。AI自身不确定、内部返回矛盾、接口失败时继续待确认。
- 复用旧缓存中的结构化AI判断重新决策；以前因本地复核失败而挡住的AI明确发票结果可直接恢复，不重复付费。独立上传授权、调用去重、缓存、失败不删除继续有效。

测试仅使用临时目录、虚构数据与模拟HTTP，不调用真实API、不读真实密钥、不删除测试文件。用户提供的PDF已在隔离目录中手动导入成功，并完成金额提取；原文件未改动。

九组离线回归均通过：手动导入/冒号文件名/重复缓存恢复、AI明确结果优先与旧缓存复用、项目手动信任和金额保护、邮箱自动分类、旧规则恢复、抬头补充、邮箱编码与订单金额日期。Mac1.34（构建38）完整编译、应用签名检查及安装包完整性校验均通过。真实界面与真实API仍需人工验收。
