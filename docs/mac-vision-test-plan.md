# Mac 订单视觉识别测试版

基准为正式 Mac 1.34；不修改 Windows 或发布到 GitHub。

- 独立名称、眼睛 TEST 图标、Bundle ID、偏好设置、钥匙串服务及数据目录，与正式版并存。
- 用户开启 AI 和独立截图上传授权后，每张新导入的非重复订单均发送截图及本地识别文字，允许 OCR 为空；不再只等本地失败。
- 明确的视觉结果可替换未人工修改的本地金额、日期和分类。金额不确定或退款/收入时保留待处理及合格候选；人工修改和过期请求结果保护继续有效。
- 同一导入记录只自动尝试一次，重新打开已保存项目不自动重复付费。提供“重测选中订单”以便更换模型后主动比较。
- 使用既有服务商/接口/模型配置，测试版需重新配置支持图片的模型；原版密钥不自动迁移。截图可能含个人及企业信息，授权默认关闭，界面明确说明上传范围及费用。
- 仅运行离线模拟请求、规则和双构建隔离检查，不连接真实 API 或邮箱。交付独立 DMG，由用户实机测试。
