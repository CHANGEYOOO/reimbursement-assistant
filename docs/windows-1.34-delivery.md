# Windows 1.34 与 Mac 1.34 同步说明

本次在原有 Windows 1.27 基础上同步 Mac 1.28–1.34 的业务流程，保留中文界面、相同图标、现有 Windows 本地资料及系统加密密钥。

## 同步内容

- 左侧项目入口、固定创建顺序、无变化不改写项目资料。
- 订单与发票统一右侧预览、适合宽度、缩放及 PDF 翻页。
- 按需查看邮件正文与外链、设置中手动检查 GitHub 更新。
- 自动订单 AI、金额候选、日期补年与手动内容保护。
- 电子发票、非发票、待确认三态；PDF、图片、XML、OFD 及 ZIP 导入。
- 手动导入信任为发票，仅提取金额和抬头；重复导入恢复文件并保留用户填写内容。
- 邮箱附件先本地筛选，只有未知且已单独授权时自动上传文字与页面图至现有 AI；AI明确结果优先，失败保留待确认。
- AI内容缓存与并发去重；可单独关闭发票AI及清除识别缓存。
- 已有邮箱后台收票、托盘、通知、自启动、缓存容量、项目归属、发票独立导出继续保留。

## 平台边界

Windows 使用本机 Tesseract/PdfPig，Mac 使用 Vision/PDFKit，因此相同图像的原始 OCR 字符可能不同；订单文字/位置规则用同组样例核对。Windows 邮件正文采用纯文本显示并列出外链，不保留 Mac HTML 排版，不会执行脚本或自动读取远程资源。

结构化 XML/OFD 支持明确的发票字段布局；未知结构保留待确认。OFD/XML 暂无可靠页面渲染时不会调用多模态AI。发票AI需要所配置模型支持图片，独立授权默认关闭。失败缓存避免反复付费，需重试时可清除AI缓存。

安装器适用于 Windows x64，包含运行时及OCR依赖；未进行商业代码签名。真实电脑界面、QQ邮箱及实际API仍由用户验收。
