# Mac 1.29：统一右侧预览

此版本取代 Mac1.28 的灯箱预览交互，其他功能和识别规则保留。

- 订单截图：选中订单或点击缩略图，在原有右侧栏显示；点击栏内图片不再弹出放大浮层。
- 发票箱：点击缩略图、文件名或预览按钮，在可调整宽度、可收起的右侧栏查看；预览选中与批量勾选独立。
- 项目发票夹同样使用右侧附件预览，不打开外部 PDF 软件或独立窗口。
- 图片保留滚动、缩放与复位；PDF 支持翻页和原文件显示。切换附件会复位页码与缩放。
- 邮件详情与发票预览互斥，避免多个右侧栏同时挤占空间。
- 异步预览仅显示最新选择，正在查看的发票缓存受保护；关闭或切换时释放保护，恢复缓存维护。

订单、发票分类与金额规则、自动AI、邮箱收票、更新检查以及项目管理没有改变。Windows仍暂停。

已通过完整编译和离线侧栏/缩略图/缓存检查，安装包另行进行签名与DMG校验；真实交互仍需人工验收。
