# 发票箱图文使用指南

适用于报销单助手 **1.34**。本文截图为 **Mac 1.34 演示数据**；Windows 的主要操作相同，入口差异见文末。

[返回软件首页](../README.md)

**先做报销单，再补足发票，最后分别导出。** 发票不需要与每张订单截图一一对应，只需要按你的工作要求补足项目总金额。

| 放在哪里 | 用来做什么 |
| --- | --- |
| 订单截图 | 填写本次实际支出，生成 Excel 报销单 |
| 发票箱 | 统一收集发票，查看哪些尚未使用、哪些已加入项目 |
| 项目发票夹 | 存放本次报销要提交的发票，单独导出文件夹 |

## 1. 先准备一个报销项目

点击左下角“新建项目”，填写报销单标题，再点击“导入截图”，批量选择支付截图。也可以把图片从文件夹直接拖进窗口。

![Mac 1.34 演示：项目、订单列表与右侧截图预览](images/guide/mac-orders.png)

检查软件填写的日期、用途和金额。选中订单后，可以在右侧查看原图；需要修改时，直接在对应栏输入。

![Mac 1.34 演示：金额候选和待处理订单](images/guide/mac-candidates.png)

金额无法确定时，点击正确的候选金额，或手动输入。勾选“只看待处理”，也可以点击“查看待处理问题”定位需要补充的订单。

项目会自动保存在当前电脑，下次打开可以继续编辑。填写完毕后点击“导出 Excel”；发票文件在后面的步骤单独导出。

## 2. 把发票放进发票箱

点击左侧“发票箱”，有两种收集方式：

- **手动导入**：点击“导入发票”，或把文件拖进窗口。支持 PDF、图片、OFD、XML 和 ZIP。
- **邮箱收集**：连接 QQ 邮箱后，同步收到的发票附件。连接步骤见第 5 节。

![Mac 1.34 演示：发票箱的月份、筛选与项目归属](images/guide/mac-inbox.png)

手动导入的文件视为你已确认是发票，软件只提取金额和抬头，不再判断票种。金额优先读取文件名中的明确金额，没有唯一金额时再识别票面；识别不准可以手动修改。

邮箱自动收取的附件会先在本地筛选：

| 结果 | 你会看到什么 |
| --- | --- |
| 电子发票 | 已确认为支持的普通或专用电子发票，可以加入项目 |
| 非发票附件 | 行程单、住宿明细、消费清单等，不计入发票金额 |
| 待确认 | 暂时看不清或无法判断，文件保留，可预览后人工确认 |
| 待下载附件 | 历史附件尚未取回，点击“下载”或“下载并预览”后识别 |

这是附件类型筛选，不代表已完成税务验真。

## 3. 选择发票，加入对应项目

1. 按“本月”“上月”等月份查看。邮件发票按**收到邮件的日期**排序；手动导入按导入日期排序。
2. 需要时，按购买方抬头、收件日期或“未加入 / 已加入”筛选。
3. 勾选要使用的发票。点击月份标题，可以批量选择该月当前筛选中尚未加入项目的合格发票。
4. 查看已选张数和金额，点击“加入项目”，选择本次报销项目。

加入后，卡片显示绿色的“已加入 · 项目名称”。发票仍保留在发票箱中，项目中保存一份副本。

同一文件不能重复加入不同项目。选错项目时，先从项目发票夹移除，再重新分配。缺少有效金额的发票，请先补金额。

## 4. 检查差额，导出发票文件夹

打开对应项目，切换到“项目发票夹”。也可以在这里点击“导入发票”，直接补充本项目的发票；已有的发票可通过“从发票箱选择”加入。

![Mac 1.34 演示：项目发票夹中的合计、差额与导出入口](images/guide/mac-project-invoices.png)

核对发票合计与订单金额，按工作要求补足差额，再点击“导出发票文件夹”。如果订单金额尚未处理完，差额会显示为“暂估”。

导出的文件夹例如 **2026-10-30-1280.50**，含义是“导出当天日期-发票总金额”。

- 发票保留原文件格式，不放入 Excel，也不按抬头拆分文件夹。
- 导出是复制文件，不会顺便清理缓存；重复导出不会覆盖已有文件夹。
- 提交报销时，按要求提交 **Excel 报销单 + 发票文件夹**。

## 5. 可选：连接 QQ 邮箱，自动收票

不连接邮箱，也可以手动导入发票。

![Mac 1.34 演示：QQ 邮箱设置](images/guide/mac-settings-mail.png)

1. 打开左下角齿轮“设置”，选择“QQ 邮箱”。
2. 在 QQ 邮箱开启 IMAP 服务并生成授权码，将邮箱地址和授权码填入软件。**授权码不是 QQ 登录密码。**
3. 选择从哪天开始收集，测试连接后保存并启用。
4. 返回发票箱，点击“同步邮箱”；之后软件运行、电脑联网且未休眠时，默认每 5 分钟检查一次。

首次开始同步后，新收到的发票附件会自动下载并识别；之前的历史附件按需下载。软件不会改变邮件已读状态，也不会删除邮件。

软件收集收件箱中具有发票提示的邮件附件，不直接同步 QQ 邮箱自带的“发票助手”。邮件只有下载链接时，请在邮箱中下载后手动导入；需要查看来源时，可在软件中打开邮件详情。Windows 的邮件正文以纯文本显示。

### 后台与通知

在“设置 → 后台与通知”中，可以开启新发票通知和登录启动。这两个开关默认关闭；关闭通知不会停止收票。

关闭主窗口后软件仍可后台运行。Mac 从顶部菜单栏图标打开或退出，也可按 `⌘Q` 退出；Windows 从右下角托盘图标打开或退出。完全退出或电脑休眠时不会持续收票，下次启动同步后补收。

## 6. 可选：让 AI 处理本地无法判断的附件

不开启 AI，也可以正常使用。

![Mac 1.34 演示：AI 设置与独立的发票上传授权](images/guide/mac-settings-ai.png)

![Mac 1.34 演示：AI 接口、模型、密钥与保存按钮](images/guide/mac-settings-ai-configuration.png)

在“设置 → AI 辅助识别”填写服务商、接口地址、模型和密钥，测试连接后保存。订单 AI 与发票 AI 的发送范围不同：

| 功能 | 什么时候调用 | 会发送什么 |
| --- | --- | --- |
| 订单 AI | 已启用 AI，本地无法确定金额、日期或用途时 | 截图中识别出的文字 |
| 发票 AI | 同时启用 AI 和独立的发票上传授权，本地无法判断邮箱附件时 | 附件提取文字与页面预览图 |

**发票上传授权默认关闭。** 票面可能包含姓名、税号、账号、地址等个人及企业信息，请根据自己的工作要求决定是否开启。手动导入的发票不调用票种判断 AI，邮件正文也不发送给 AI。

开启发票授权并保存后，新收到及已有的待确认附件会自动接续识别，不需要逐张点击。本地已明确判断的附件不调用 AI；本地待确认时采用 AI 的明确结果。AI 自身不确定、返回矛盾或调用失败，仍保留待确认，不删除文件。

发票 AI 需要支持图片输入的模型；普通连接测试只验证文字连接。无法生成可靠页面预览的 OFD/XML 继续保留待确认。

AI 服务可能收费。识别结果和失败结果都会缓存，避免同一文件重复请求；需要重试时，可以在设置中清除发票 AI 缓存。清除后再次识别可能收费，不会删除发票文件。

密钥和邮箱授权码在 Mac 保存在钥匙串，在 Windows 使用当前用户的系统加密保存。不要把真实密钥放进截图或反馈中。

## 删除记录与清理缓存，有什么不同？

| 操作 | 结果 |
| --- | --- |
| 在发票箱点“删除”，或勾选后点“删除所选” | 删除发票箱记录及其本地缓存；项目副本、已导出文件和邮箱原件保留 |
| 从项目发票夹移除发票 | 从本项目移除，发票箱中的原件仍可重新分配 |
| 在“设置 → 缓存管理”清理 | 清理可从邮箱重新下载的附件文件，保留记录、金额与项目归属 |

缓存默认上限为 **200 MB**，可以自行设置。超出上限时，优先清理最久未使用的可恢复缓存。手动导入、项目副本及已导出文件不会被缓存管理清理。

缓存文件移入 Mac 废纸篓或 Windows 回收站；要真正释放磁盘空间，请自行检查后清空。重新下载的前提是邮箱原件仍可访问，重要资料请另行备份。清理失败时自动清理会暂停，可在设置中重试。

## Windows 入口对照

| 要做什么 | Mac 1.34 | Windows 1.34 |
| --- | --- | --- |
| 创建报销项目 | 左下“新建项目” | 左侧“新建报销单” |
| 查看本项目发票 | 项目内顶部切换“项目发票夹” | 左侧“项目发票夹” |
| 从发票箱补充发票 | “从发票箱选择”，或左侧“发票箱” | 左侧“发票箱”勾选后“加入项目” |
| 打开设置 | 左下齿轮 | 左侧“设置” |
| 查看合格发票 | 筛选“电子发票” | 筛选“发票” |
| 后台打开 / 退出 | 顶部菜单栏图标 | 右下角托盘图标 |
