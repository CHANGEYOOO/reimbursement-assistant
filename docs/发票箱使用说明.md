# 发票箱使用说明（Mac 1.24）

左侧“发票箱”统一收集发票；“我的项目”继续使用原有报销单。旧项目资料无需重新导入。

## 连接 QQ 邮箱

在左侧点击“设置”，选择“QQ 邮箱”，填写 QQ 邮箱地址和邮箱授权码。授权码需要在 QQ 邮箱开启 IMAP 服务后生成，不是 QQ 登录密码，也不要发送到聊天中。

测试连接后，选择开始收集的日期并保存启用。默认范围为最近30天，可往前选择以收集历史邮件。软件运行、电脑联网且未休眠时，每5分钟同步邮件信息，也可手动点击“同步邮箱”。完全退出或电脑休眠期间收到的邮件会在下次同步时补收。

## 按需下载

同步只登记发票附件名称、邮件来源和收件时间，**不会自动下载附件**，也不改变邮件已读状态或删除邮件。

未下载的卡片显示“未下载”；文件名没有明确金额时，金额和抬头会提示下载后识别。点击“下载”、“下载并预览”或“下载并加入项目”才会取回附件。已下载的文件保存在当前电脑，之后预览无需重复下载。

发票箱按邮件收件日期从新到旧排列，分为本月、上月和更早月份；补收旧邮件仍使用原收件时间。手动上传使用导入时间。支持按购买方抬头、收件日期和分配状态筛选。

## 加入项目

勾选发票后点击“加入项目”，选择对应项目。也可以先进入项目的“项目发票夹”，点击“从发票箱选择”。未下载的票会在你确认加入时下载，再识别金额和抬头；需要处理的金额请先修改。

加入后，发票仍保留在发票箱并显示所属项目；项目发票夹按原有方式统计金额与导出。一张相同文件的发票不能重复加入不同项目。从项目发票夹移除后，发票箱里的原件保留，可重新分配。发票不需要与订单逐条对应。

## 暂不能自动处理的情况

目前处理 QQ 邮箱收件箱中主题或附件名称具有发票标识的邮件附件，支持 PDF、图片和 ZIP。不直接同步 QQ 邮箱自带的发票助手，也不会自动下载邮件正文里的链接。未发现可导入附件的发票邮件会列出提醒，请在 QQ 邮箱查看后手动下载导入。

抬头或金额识别不准确时，可在未分配卡片上点击编辑修正。附件过大、格式特殊或邮件已移出收件箱时，也可能需要手动下载导入。

QQ 邮箱授权码仅保存在 Mac 钥匙串；邮件和发票不会交给 AI 进行识别。新功能没有经过真实邮箱验收，请先用少量邮件检查收件日期、下载和项目归属。

## 后台收票与通知

点击窗口左上角关闭按钮，只隐藏主窗口，软件继续在后台收集发票邮件信息，附件仍不会自动下载。Mac 顶部菜单栏会显示图标，可以打开窗口、查看上次同步与未分配张数、立即同步或完全退出。按 ⌘Q 或在菜单选择“退出”才会停止收票。

在“设置 → 后台与通知”中可以调整“新发票通知”和“登录 Mac 后自动启动”。主界面左侧、顶部菜单栏的“设置”以及 ⌘, 都打开同一个设置窗口；AI 配置位于“AI 辅助识别”，邮箱连接位于“QQ 邮箱”。两个开关默认关闭，通知开关不影响邮箱同步。首次开启通知需要允许 macOS 通知权限；系统拒绝时，请到“系统设置 → 通知 → 报销单助手”允许。

一次同步收集到的新发票合并为一条通知；首次连接或扩大日期范围补收历史邮件，完成后只提示汇总，不逐张弹出。点击通知会打开全局发票箱。通知只包含张数，不展示公司抬头、金额或邮件内容。

登录启动使用 Mac 系统登录项设置，可能需要到“系统设置 → 通用 → 登录项”允许；请先把应用安装到“应用程序”文件夹。未开启时不会注册登录启动。后台收票仍要求电脑已登录、联网且未休眠，不会唤醒休眠的电脑。

## 金额与附件类型

金额优先对应票面的“价税合计（小写）”，区分税前金额、税额及明细。文字提取顺序与票面不同的 PDF，会按字段位置寻找金额；图片或扫描件使用本地文字识别。无法唯一确定时由你手动填写，不默认取最大数字。

邮件同步先根据附件名排除明确的行程明细、报销汇总等材料；按需下载后，再结合票面标题、发票号码、日期和金额等内容判断。正式的航空运输电子客票行程单、铁路电子客票仍保留。无法确认的文件显示“待确认附件类型”，请先预览，再选择“确认为发票”。排除的文件可以在“附件类型 → 已排除附件”中查看、删除；旧项目中已经加入的附件请人工复核。类型判断不等于税务验真。

已下载但缺金额或抬头的文件会在启动时本地补识别，保留已填金额、抬头和项目归属。手动重新识别按钮已取消。

## 删除发票箱记录

可删除单张，也可勾选多张后点击“删除所选”。确认后仅删除发票箱记录，并将其本地缓存移入废纸篓；项目副本、已导出文件和邮箱邮件不受影响。正在处理或加入项目中的文件不能删除。

## 缓存管理

在“设置 → 缓存管理”查看可清理缓存占用、填写自定义上限，或手动清理全部可恢复缓存。默认值为 200 MB，可自行修改，并非固定上限。

超出上限时，软件优先清理最久未使用的缓存。下载、预览后及后台定期检查都会触发检查；正在使用的文件稍后处理。清理后保留发票记录、金额、抬头和项目归属，需要时可再次下载，前提是邮箱原件仍可访问；请勿把缓存清理当作资料备份。

仅清理具有独立邮箱下载来源的附件。手动导入文件、无法单独恢复的 ZIP 子文件、项目副本及已导出文件保留。缓存移入废纸篓后可恢复；需要真正释放磁盘空间，请自行检查并清空废纸篓。清理失败会立即停止并暂停自动清理，可在设置中重试。导出操作仍是复制，不附带清理。
